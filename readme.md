# Estudos de bases de dados e análise

Coleção de exercícios com Python, notebooks e arquivos de dados. Cada pasta reúne um estudo independente, para acompanhar a leitura, a organização e a análise das tabelas.

## Conteúdo

- `Projects/IceCream/`: notebook e arquivos do estudo de vendas de sorvetes.
- `Projects/Project - Analise de Dados/`: aulas de Python, NumPy, Pandas, leitura de arquivos, gráficos e preparação de dados.
- `Projects/TitanicProject/`: notebook da análise do Titanic e os CSVs correspondentes.

## Como usar

Abra o notebook do estudo no Jupyter ou em um editor com suporte a notebooks. Execute a partir da pasta daquele exercício para manter os caminhos relativos dos arquivos de dados.

Não há um comando único que execute toda a coleção. Confira as importações de cada notebook e instale apenas as bibliotecas necessárias ao estudo escolhido.
